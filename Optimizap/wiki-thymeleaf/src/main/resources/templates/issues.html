📋 Estado del Trabajo (Issues)

El desarrollo del backend del proyecto Organizapp se gestionó mediante el uso de issues en GitHub, permitiendo organizar el trabajo, asignar responsabilidades y hacer seguimiento al avance del proyecto.

A través de reuniones periódicas, el equipo definió tareas específicas, responsables y fechas de entrega, asegurando el cumplimiento de los objetivos.

Metodología de trabajo

  • GitHub Issues para dividir el trabajo
  • Pull Requests para revisión de código
  • Actas de reunión para seguimiento del avance
  • Trabajo colaborativo por roles

Implementación de Entidades y Repositories

El proyecto se centró en la implementación de entidades del dominio y sus correspondientes repositories para acceso a datos.
